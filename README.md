# Proyecto01

Proyecto web desarrollado con Django para gestionar productos, usuarios, noticias y una vista de contacto. Es un proyecto sencillo pensado para practicar desarrollo backend y frontend con Python.

## Tecnologías

- Python
- Django
- SQLite
- HTML / CSS / JavaScript

## Funcionalidades

- Catálogo de productos
- Registro y gestión de usuarios
- Sección de noticias
- Página de contacto
- Panel administrativo de Django

## Requisitos

- Python 3.10 o superior
- pip

## Instalación

```bash
git clone <url-del-repositorio>
cd Proyecto01
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows
pip install django
python manage.py migrate
python manage.py runserver
```

## Ejecutar

Abre en tu navegador:

```text
http://127.0.0.1:8000/
```
